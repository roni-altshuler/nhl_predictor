# Security reporting and scope

The current program reads local CSV/JSON files and writes historical evaluation outputs. It has no web server, account system, credentials, provider downloader or deployed service. This does not constitute a security guarantee.

Do not post credentials, private datasets, signed transfer links, access logs or other sensitive material in public issues. Coordinate a confidential reporting method with the maintainer before sending sensitive details. No dedicated confidential disclosure address or response-time commitment is advertised here.

For non-sensitive defects, include the affected commit, Python version, a minimal artificial input and reproducible steps. Avoid private source files. Preserve original evidence rather than overwriting it, and do not run unsolicited scans against a provider or unrelated service.
