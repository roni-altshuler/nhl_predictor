# Synthetic input only

The two fixture files in this directory contain artificial data for tests and the reproducible example. They are not observed NHL games and do not establish prediction accuracy or provider compatibility.

The manifest identifies `synthetic-contract-fixture` and the CSV's byte hash. The source URL is null because this is not a provider download. No original pre-game publication timestamp is asserted.

External datasets, acquisition records and generated evaluations must remain outside the repository. See [data-source requirements](../docs/DATA_SOURCES.md) before using actual data.
